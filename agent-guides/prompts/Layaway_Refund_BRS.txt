======================================================
Existing Functionality Of LayawayRefundMasterDto
======================================================
1) Store all the columns from the  rest API: https://localhost:7184/api/LayawayRefundMaster?pageNumber=1&pageSize=1.
2) Showing following columns in the datatable from LayawayRefundMasterDto:
   ----------------------------------
   HeaderName | ColumnName | Remarks
   ----------------------------------
   Transaction Id | tbirm_InvoiceRefundIdRad | This will be generated from server side
   Customer Name | OriginalLayawayName |
   Date | tbirm_InvRefundDate | Show in dd/mm/yyyy
   Total Amount | tbirm_Total |
   Phone No | tbim_Phone |
   Refund Amount | tbirm_RefundAmt


3) Datatable has search inputs for:
   Lebel | Query Field
   Transaction No | refundTransactionId
   Invoice No | invoiceTransactionId
   Customer Name | customerName
   Phone No | phoneNo
   From Date | startDate (Date Picker)
   To Date | endDate (Date Picker)
   
4) There is a button named "New Invoice" that redirects to another form that contains Invoice Master datatable with following columns:
   ----------------------------------
   HeaderName | ColumnName | Remarks
   ----------------------------------
   Transaction Id | tbim_InvoiceIdRad | This will be generated from server side
   Customer Name | tbim_Name |
   Date | tbim_InvDate | Show in dd/mm/yyyy
   Total Amount | tbim_Total |
   Phone No | tbim_Phone |
   Payment Type | paymentMethodName
   Paid Amount | tbim_PaidAmt
   Refund Amount | RefundAmount
   Refund Type | tbim_RefundType
   
   Datatable has search inputs for query parameters:
   Lebel | Query Field
   Invoice No | invoiceTransactionId
   Customer Name | customerName
   Phone No | phoneNo
   From Date | startDate (Date Picker)
   To Date | endDate (Date Picker)  
   Payment Slot | A combo box having Key value Full->F,Partial->P,Pending->N and field name is paymentSlot
   
   In the action column of the datatable there are two button named: Item Refund and Payment Refund.
   On clicking Item Refund:
   a) On clicking Item Refund opens another window having the basic information from the related InvoiceMasterDto in Readonly mode.
      Below the InvoiceMasterDto section it shows the datatable of InvoiceDetailsDto with edit enabled.
	  Below the InvoiceDetailsDto section, it shows datatable for InvoiceRefundPaymentsDto and allows Add/Edit in that datatable.Add/Edit in this datatable opens the refund payment window through user can insert amount and Payment Method. Payment Method is a dropdown box that shows the refund payment method using https://localhost:7184/api/RefundMethodNames where Key=id and Value=tbrmn_RefundMethodName.
      Beside InvoiceRefundPaymentsDto 
	    -> It will show two options : Partial Refund (sets tbirm_RefundType to P) and Full Refund (sets tbirm_RefundType to F). Below this it shows a textarea named notes to set tbim_Note.
		-> Beside refund option, it will show all the value fields from InvoiceMasterDto like Adjusted Amoun,Subtotal,Sale Tax,Labour,discount,Total and these values changes with the entry in the InvoiceRefundPaymentsDto.
	  
	  
   b) Clicking save button maps the LayawayMasterDto to LayawayRefundMasterDto And LayawayDetailsDto to LayawayRefundDetailsDto as follows:
		===================================================
		Mapping LayawayMasterDto to LayawayRefundMasterDto
		===================================================
		LayawayRefundMasterDto.Id = Identity field. Will be generated from DB.
		LayawayRefundMasterDto.tbirm_InvoiceRefundIdRad = Will be generated and saved by server.
		LayawayRefundMasterDto.tbirm_InvRefundDate = will be taken from Refund Date datepicker in the form.
		LayawayRefundMasterDto.tbirm_RefundType = "F" for Full payment, "P" for partial payment.
		LayawayRefundMasterDto.tbirm_InvoiceId = InvoiceMasterDto.Id
		LayawayRefundMasterDto.tbirm_SubTotal = InvoiceMasterDto.tbim_SubTotal
		LayawayRefundMasterDto.tbirm_SaleTax =  InvoiceMasterDto.tbim_SaleTax
		LayawayRefundMasterDto.tbirm_Labour =  InvoiceMasterDto.tbim_Labour
		LayawayRefundMasterDto.tbirm_DisPer =  InvoiceMasterDto.tbim_DisPer
		LayawayRefundMasterDto.tbirm_DisAmt =  InvoiceMasterDto.tbim_DisAmt
		LayawayRefundMasterDto.tbirm_Total =  InvoiceMasterDto.tbim_Total
		LayawayRefundMasterDto.tbirm_RefundAmt = Total Refund Amount from Refund table
		LayawayRefundMasterDto.tbirm_AdjAmt =  InvoiceMasterDto.tbim_AdjAmt
		LayawayRefundMasterDto.tbirm_Note =  InvoiceMasterDto.tbim_Note
		LayawayRefundMasterDto.tbirm_Delinfo =  InvoiceMasterDto.tbim_Delinfo
		LayawayRefundMasterDto.tbirm_Item_Delete_after_Invoice_Refund_Create =  InvoiceMasterDto.tbim_Item_Delete_after_Invoice_Create
		LayawayRefundMasterDto.UserName = Application User Names
		LayawayRefundMasterDto.SetDate =  InvoiceMasterDto.CurrentDate
		LayawayRefundMasterDto.OriginalInvoiceName =  InvoiceMasterDto.tbim_Name
		LayawayRefundMasterDto.OriginalInvoiceDate =  InvoiceMasterDto.tbim_InvDate

		===================================================
		Mapping LayawayDetailsDto to LayawayRefundDetailsDto
		===================================================
		LayawayRefundDetailsDto.Id = Identity field. Will be generated from DB.
		LayawayRefundDetailsDto.tbird_InvoiceRefundId =  Id of the LayawayRefundMaster. Will be inserted automatically during the first creation.
		LayawayRefundDetailsDto.tbird_ItemId = InvoiceDetailsDto.tbid_ItemId
		LayawayRefundDetailsDto.tbird_ItemCategory = InvoiceDetailsDto.tbid_ItemCategory
		LayawayRefundDetailsDto.tbird_DepartmentName = InvoiceDetailsDto.tbid_DepartmentName
		LayawayRefundDetailsDto.tbird_Size = InvoiceDetailsDto.tbid_Size
		LayawayRefundDetailsDto.tbird_Brand = InvoiceDetailsDto.tbid_Brand
		LayawayRefundDetailsDto.tbird_Series = InvoiceDetailsDto.tbid_Series
		LayawayRefundDetailsDto.tbird_Bolt = InvoiceDetailsDto.tbid_Bolt
		LayawayRefundDetailsDto.tbird_HoleS = InvoiceDetailsDto.tbid_HoleS
		LayawayRefundDetailsDto.tbird_Zone = InvoiceDetailsDto.tbid_Zone
		LayawayRefundDetailsDto.tbird_DistributorId = InvoiceDetailsDto.tbid_DistributorId
		LayawayRefundDetailsDto.tbird_DistributorName = InvoiceDetailsDto.tbid_DistributorName
		LayawayRefundDetailsDto.tbird_Qty = InvoiceDetailsDto.tbid_Qty
		LayawayRefundDetailsDto.tbird_Taxable = InvoiceDetailsDto.tbid_Taxable
		LayawayRefundDetailsDto.tbird_UnitPrice = InvoiceDetailsDto.tbid_UnitPrice
		LayawayRefundDetailsDto.tbird_LineTotal = InvoiceDetailsDto.tbid_LineTotal
		LayawayRefundDetailsDto.tbird_TaxAmt = InvoiceDetailsDto.tbid_TaxAmt
		LayawayRefundDetailsDto.ItemDepartmentName = InvoiceDetailsDto.ItemDepartmentName
		LayawayRefundDetailsDto.ItemDistributorName = InvoiceDetailsDto.ItemDistributorName
		LayawayRefundDetailsDto.ItemLocationName = InvoiceDetailsDto.ItemLocationName
		LayawayRefundDetailsDto.ItemDisplay = InvoiceDetailsDto.ItemDisplay
			  
        And Maps Refund Payment datatable to InvoiceRefundPaymentsDto
		
		and finaly calls the CreateRefund Api with those values.
		
		
        On clicking Payment Refund:
		Enerything will be like Item Refund Except, there will be no option for editing Items in the InvoiceDetails datatable.
		No data will be saved in the LayawayRefundDetailsDto.
