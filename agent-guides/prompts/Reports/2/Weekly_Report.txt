# BRS
1. Under Left Menu Report link, there is a submenu name Transaction Reports already developed by you. You will work on 3rd radio button (Weekly/Monthly Report) here.
2. For This radio button, there will be option for selecting From And To Date. please use the datepicker format as in the report already.
3. Data will be shown in a datatable. the datatable will be as like all other datatable used in this project with funnel filter following the same design pattern.
4. There are search and show button, and Export ComboBox already. Use them as you did for the first radio button already
5. the end point for search,show,download functionality is given in ## 2.
   Existing PDF Report has been attached herewith \agent-guides\prompts\Reports\WeeklyReport.pdf for your reference.But you have the full liberty to design following the industry standard.
6. On top of the PDF, there is company information. You will get the information from the api mentioned in 1 above. Use the fields:
   tbbiBusinessName,tbbi_Address1,tbbi_Address2
   You can follow the actions you did in the daily report for generating this header.
   Please follow the other reports to check the format to follow.
7. Please keep track of everything you are doing in a separate file for future reference.
