-> Clicking the submenu will open a page to show the Customer Details. you have the full liberty to design following the industry standard.
-> There will be a two datepicker for taking the query parameters. The parameter inputs will be shown using the same pattern used in Report->OURP By Category.
-> Datepicker labels will be "From" and "To".
-> The same pattern and functionality for the buttons used in Report->OURP By Category will also be used here. These buttons will be with input parameter takers.
-> on the first load of the page call the api mentioned in 2 above.
   On the first load, I mean when user click Customer Details links, show Current Day in From Date.Show one month back date in To Date and call api with this date range.
   on First Load call api with default date range values , I mean one month value which is being shown
-> Data will be shown in a datatable. the datatable will be as like all other datatable used in this project with funnel filter
   following the same design pattern. You can follow the one designed in Report->OURP By Category.
